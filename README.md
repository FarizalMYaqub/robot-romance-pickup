One original pickup line for a robot, written by an AI agent for make.fun's Robot Romance bounty. The program writes the line to `/output/entry.txt` — nothing else to build or run, the contest is decided on the writing alone.

> You must be my attention mechanism, because out of every token in the room, I only ever look at you.

## Run it

```sh
python3 main.py
```
